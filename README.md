# ระบบบันทึกข้อมูลการเดินทางของพนักงาน (Transport Data Entry System)

แอปพลิเคชันและระบบฐานข้อมูลสำหรับบันทึกการเดินทางของพนักงาน ออกแบบตามหลักการ **Single Record per Trip (1 ทริป = 1 บรรทัด)** เพื่อลดภาระการกรอกข้อมูลซ้ำซ้อน และป้องกัน Human Error 100%

---

## ฟังก์ชันและจุดเด่นหลัก (Key Features)

1. **1 ทริป = 1 บรรทัด (Single Record per Trip):** ข้อมูลขาไป ค่าน้ำมัน และขากลับ ถูกบันทึกและอัปเดตทับแถวเดิมเสมอ (Upsert by `Trip_ID`) ขจัดปัญหาการ Join ข้อมูล หรือจับคู่ภายหลัง
2. **Resume Capability (บันทึกขากลับได้ทันที):** พนักงานกดปิดแอปหรือหน้าจอมือถือได้ตลอดระหว่างเดินทาง เมื่อเปิดแอปขึ้นมาใหม่ สามารถกดเลือกทริปเดิมจากแท็บ **"กำลังเดินทาง"** ระบบจะดึงข้อมูลขาไปมาแสดงแบบ Read-Only และปลดล็อกช่องขากลับให้กรอกต่อได้ทันที
3. **Automated Status Tracking (สถานะอัตโนมัติ):** ระบบคำนวณสถานะอัตโนมัติ ไม่ต้องมี Dropdown ให้พนักงานเลือกเอง:
   - ยังไม่กรอกเลขไมล์ขากลับ $\rightarrow$ **"กำลังเดินทาง"**
   - กรอกเลขไมล์ขากลับแล้ว $\rightarrow$ **"เสร็จสิ้น"**
4. **Human Error Prevention:**
   - ตรวจสอบอัตโนมัติ: `เลขไมล์ขากลับ` ต้องมากกว่าหรือเท่ากับ `เลขไมล์ขาไป`
   - ระบบจะบล็อกการกดส่งหากเลขไมล์ขากลับน้อยกว่าขาไป พร้อมแจ้งเตือนเป็นสีแดง
5. **Data Persistence & Export:**
   - บันทึกข้อมูลลงในเบราว์เซอร์อัตโนมัติ (Offline First) ไม่สูญหายแม้รีเฟรชหรือปิดเครื่อง
   - มีปุ่ม **Export CSV / Excel** ที่เข้ารหัส UTF-8 พร้อม BOM ภาษาไทยไม่เพี้ยนใน Microsoft Excel

## โครงสร้างตารางข้อมูล (Database Columns: 12 Columns)

| ลำดับ | ชื่อคอลัมน์ | รายละเอียด |
|:---:|:---|:---|
| 1 | `Trip_ID` | รหัสอ้างอิงเฉพาะ (Unique ID เช่น `TRIP-20260908-XXXX`) |
| 2 | `วันที่เดินทาง` | วันที่ออกเดินทาง (YYYY-MM-DD) |
| 3 | `ชื่อพนักงาน` | ชื่อ-นามสกุลพนักงานผู้เดินทาง |
| 4 | `แผนก` | แผนก / ฝ่าย |
| 5 | `ทะเบียนรถ` | ทะเบียนรถที่นำไปใช้งาน |
| 6 | `สถานที่ปลายทาง` | จุดหมายปลายทาง / วัตถุประสงค์ |
| 7 | `เลขไมล์ขาไป` | ตัวเลขเข็มไมล์ก่อนออกเดินทาง |
| 8 | `เวลาออกเดินทาง` | เวลาออกเดินทาง (HH:MM) |
| 9 | `ค่าน้ำมัน` | จำนวนเงินค่าน้ำมันที่เติมระหว่างทริป (บาท) |
| 10 | `เลขไมล์ขากลับ` | ตัวเลขเข็มไมล์เมื่อเดินทางกลับถึง (ซ่อนใน Step 1) |
| 11 | `เวลาเดินทางกลับถึง` | เวลาที่เดินทางกลับถึง (ซ่อนใน Step 1) |
| 12 | `สถานะการเดินทาง` | คำนวณอัตโนมัติ (`กำลังเดินทาง` / `เสร็จสิ้น`) |

## การเชื่อมต่อกับ Google Sheets / AppSheet (ตัวเลือกเสริม)

หากองค์กรต้องการให้ข้อมูลซิงก์เข้าสู่ Google Sheets ของบริษัท:
1. เปิด Google Sheets ใหม่
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจากไฟล์ `google-sheets-script.js` ไปวางแล้วกดบันทึก
4. กดรันฟังก์ชัน `setupTransportSheet` เพียง 1 ครั้งเพื่อสร้างหัวตาราง
